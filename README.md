# Basic HTML Website

A basic portfolio website built with HTML, focusing on semantic HTML structure without CSS or JavaScript.

## Pages

- `homepage.html` - Homepage and personal introduction
- `projects.html` - Details about each project
- `articles.html` - Articles page
- `contact.html` - Contact information and contact form

## Features

- Multi-page website structure
- Navigation bar linking all pages
- Semantic HTML elements such as `header`, `nav`, `main`, `section`, `article`, and `footer`
- Links from the homepage to the relevant project sections
- Contact form with name, email, subject, and message fields

## Getting Started

Open `homepage.html` in a web browser to view the website.
